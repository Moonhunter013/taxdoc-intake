# Blank IRS forms

Put the official fillable PDFs here (downloaded from irs.gov):

- `fw2.pdf` (Form W-2): https://www.irs.gov/pub/irs-pdf/fw2.pdf
- `f1099nec.pdf` (Form 1099-NEC): https://www.irs.gov/pub/irs-pdf/f1099nec.pdf

`../generate_forms.py` fills them with the fictional clients in `../clients.json`.
